Setting the Omarchy screensaver branding

Install figlet, render "AI Karyashala" as an ASCII banner into Omarchy's branding folder, then trigger the screensaver to see it applied.

terminal

$cd ~/.config/omarchy/branding
$sudo pacman -Sy figlet
$figlet -f slant "AI Karyashala" > screensaver.txt

Want to preview the banner text and download screensaver.txt without touching a terminal? Use the name → file.txt generator.

The steps

cd ~/.config/omarchy/branding
Move into Omarchy's branding directory — this is where screensaver text and other identity assets live.
sudo pacman -S figlet
Refresh the pacman package index and install figlet, the ASCII-art banner generator.
figlet -f slant "AI Karyashala" > screensaver.txt
Render "AI Karyashala" in the slant font and write it to screensaver.txt, the file Omarchy reads for the screensaver banner.
Super + Esc + Enter
Omarchy's shortcut to lock the screen, triggering the screensaver so you can preview the new branding immediately.
